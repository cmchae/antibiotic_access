# Antibiotic access and child mortality in low- and middle-income countries

This repository contains the analysis code and publicly shareable data associated with the manuscript:

**Antibiotic access and child mortality in low- and middle-income countries**

The analysis estimates the incidence and mortality burden of lower respiratory tract infection (LRTI) and acute febrile illness (AFI) among children younger than 5 years in low- and middle-income countries, and evaluates the potential reduction in mortality associated with improved access to effective antibiotic treatment.

## Reproducibility

Three analysis routes are documented.

### 1. Public reproduction of the main analysis

The publicly supported reproduction workflow for the main analysis begins with `Final_10`.

Analysis checkpoint files required for the downstream analyses are archived separately on Zenodo. These checkpoints allow reproduction of the downstream estimates, tables, and figures without redistribution of individual-level DHS microdata or the original IHME/GBD source-data extracts.

> [!IMPORTANT]
> **To reproduce the downstream main analyses:**

> 1. Clone or download this repository.
> 2. Download the main-analysis checkpoint files from the associated Zenodo record.
> 3. Place the checkpoint files in the `outputs/` directory as specified in `outputs/README.md`.
> 4. Use the repository root as the working directory.
> 5. Run `scripts/Final_10_Extrapolation_and_absolute_number_revised.R`.
> 6. Continue through `Final_19` as needed.

See `outputs/README.md` and `scripts/README.md` for the required checkpoint files and additional instructions.

### 2. Public reproduction of the sensitivity analysis

The publicly supported sensitivity-analysis workflow begins with `Final_21`.

Sensitivity-specific checkpoint files are archived in the same Zenodo record. These files allow reproduction of the downstream sensitivity-analysis estimates, tables, and figures without access to the individual-level DHS microdata or original IHME/GBD source-data extracts.

> [!IMPORTANT]
> **To reproduce the sensitivity analysis:**

> 1. Download the sensitivity-analysis checkpoint files from the associated Zenodo record.
> 2. Place them in `outputs/sensitivity_analysis/` as specified in `outputs/README.md`.
> 3. Ensure the required shared checkpoint files are present in `outputs/`.
> 4. Run `scripts/Final_21_Sensitivity_analysis_from_checkpoint.R`.

The complete sensitivity-analysis workflow, including upstream processing, is documented in `scripts/Final_20_Sensitivity_analysis.R`.

### 3. Upstream processing from source data

Scripts `Final_00`–`Final_09` document the upstream analytical workflow used to generate the analysis-ready datasets and main-analysis checkpoint files.

`Final_20_Sensitivity_analysis.R` similarly documents the complete sensitivity-analysis workflow from the upstream data-processing stages.

These workflows use data from multiple sources, including:

- Demographic and Health Surveys (DHS)
- Institute for Health Metrics and Evaluation (IHME) Global Burden of Disease (GBD) data
- antibiotic consumption data from One Health Trust
- World Bank indicators
- WHO data
- other publicly available country-level covariates

Some source datasets are not redistributed through this repository. In particular:

- individual-level DHS microdata must be obtained directly from The DHS Program;
- specific IHME/GBD data extracts used in the original analysis must be reconstructed from the corresponding source data; and
- antibiotic consumption data used in the upstream analysis should be obtained directly from One Health Trust.

The upstream workflows are therefore provided primarily for transparency and documentation and are not intended to be fully self-contained without independently obtaining and preparing the required source-data inputs.

See `data/README.md` and `data/datasets/README.md` for details.

## Data availability

Several publicly shareable country-level input datasets are included in the `data/` directory.

Other source data used in the upstream analysis should be obtained directly from the original providers:

- **Demographic and Health Surveys (DHS):** https://dhsprogram.com/data
- **Antibiotic consumption data:** https://resistancemap.onehealthtrust.org/AntibioticUse.php
- **IHME/GBD data:** corresponding source data should be obtained from IHME and used to reconstruct the extracts required by the upstream scripts.

The expected structure and location of these source files are documented in `data/README.md`.

All analysis checkpoint files required for the publicly supported downstream reproduction workflow are archived separately on Zenodo.
