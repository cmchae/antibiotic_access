# Analysis checkpoint files

This directory is used for analysis outputs generated by the R scripts.

Large intermediate files are not stored directly in the GitHub repository. Publicly shareable checkpoint files needed to reproduce the downstream analyses are archived separately on Zenodo.

## Public reproduction

Two publicly supported reproduction workflows are available: the main analysis and the sensitivity analysis.

### 1. Main analysis

To reproduce the main downstream analyses without access to the original DHS microdata or upstream IHME/GBD source files:

1. Download the checkpoint files from the associated Zenodo record.
2. Place the following files directly in the `outputs/` directory.
3. Run the analysis beginning with `scripts/Final_10_Extrapolation_and_absolute_number_revised.R`.

The required main-analysis checkpoint files are:

- `UNI_indexed.rds`
- `coef_df_LRI.rds`
- `coef_df_Fever.rds`
- `coef_df_LRI_DDD.rds`
- `coef_df_Fever_DDD.rds`
- `coef_df_all_DDD.rds`
- `matrix.result.ver.1.rds`
- `matrix.result.ver.2.rds`
- `U5_DDD_LRI_matrix.rds`
- `ab.data_LRI.UNI.rds`
- `health_expenditure.rds`

These files contain analysis-ready country-year estimates, simulation results, and fitted-model parameters required by the downstream main-analysis scripts. Individual-level DHS records are not included.

### 2. Sensitivity analysis

The public sensitivity-analysis workflow uses a separate set of checkpoint files generated after the upstream sensitivity-analysis processing.

Place the following files in `outputs/sensitivity_analysis/`:

- `SA_UNI_indexed.rds`
- `SA_coef_df_LRI.rds`
- `SA_coef_df_Fever.rds`
- `SA_coef_df_LRI_DDD.rds`
- `SA_coef_df_Fever_DDD.rds`
- `SA_coef_df_all_DDD.rds`
- `SA_matrix.result.ver.1.rds`
- `SA_ab.data_LRI.UNI.rds`
- `SA_U5_DDD_LRI_matrix.rds`

The sensitivity analysis also uses `health_expenditure.rds` from the main-analysis checkpoint files in the `outputs/` directory.

After placing the required checkpoint files in the locations above, run:

`scripts/Final_21_Sensitivity_analysis_from_checkpoint.R`

This reproduces the downstream sensitivity-analysis estimates, tables, and figures without requiring access to the individual-level DHS microdata or the original IHME/GBD source-data extracts.

The complete upstream sensitivity-analysis workflow is documented in `scripts/Final_20_Sensitivity_analysis.R`.

The downstream scripts will create additional subdirectories and files within `outputs/` as needed.

## Upstream processing from source data

The scripts beginning with `Final_00_DHS_data.R` document the upstream processing used to generate the main-analysis checkpoint files.

Running these scripts requires users to independently obtain the required DHS and IHME/GBD source data and, where applicable, reconstruct the source-data extracts used in the original analysis.

Similarly, `Final_20_Sensitivity_analysis.R` documents the complete sensitivity-analysis workflow, including the upstream processing used to generate the sensitivity-specific checkpoint files.

Because the required DHS and IHME/GBD upstream inputs cannot be redistributed through this repository, these upstream workflows are provided primarily for transparency and documentation.

## Zenodo

The Zenodo archive contains the checkpoint files required for public reproduction of both the main analysis beginning with `Final_10` and the sensitivity analysis beginning with `Final_21`.

**Zenodo DOI:** 10.5281/zenodo.23682053  

**Zenodo record:** https://doi.org/10.5281/zenodo.23682053
